# Evidence boundary

| State                          | What it proves                                                 | What it does not prove                                             |
| ------------------------------ | -------------------------------------------------------------- | ------------------------------------------------------------------ |
| Local SQLite event             | Reeti recorded a local workflow state                          | Minds remembered, Telegram sent, public deployment, or submission  |
| Official Minds client response | The provider responded for the configured Mind                 | Product adoption, public availability, or durable business value   |
| Two-process proof artifact     | The documented test observed cross-process provider continuity | All memory behaviors, deletion guarantees, or production retention |
| Telegram message ID            | Telegram accepted one private delivery                         | Public social publishing or creator approval                       |
| Local browser smoke            | The UI is reachable and interactive locally                    | Public URL or portal submission                                    |

Never promote a claim across rows without new evidence. The private event claim ledger is the
canonical release checklist for these boundaries.
